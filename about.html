Aeronautical engineering and drones

I use aeronautical engineering to treat a drone as one system. Lift, drag, weight, power and control all pull against each other, so every design choice is a trade-off, and I enjoy finding the balance.

Build log

How I build a drone from scratch

I don't buy a ready-made kit. I start from an empty page and work through these steps.

1. Define the mission

What should it carry, how long should it fly, and where? These answers set the size, weight and battery budget.

2. Design the airframe

I model the frame in CAD, then 3D print it or cut it from carbon fibre. I keep it light and stiff and check where the centre of gravity ends up.

3. Choose the propulsion

Motors, propellers, speed controllers and battery have to match. I calculate thrust and efficiency so the drone can hover with plenty of margin.

4. Wire the electronics

I solder the power system and connect the flight controller, radio, GPS and sensors, keeping the wiring short and tidy.

5. Set up the software

I configure the flight controller firmware, then tune the control loops until the drone is stable and responds smoothly.

6. Test and improve

Bench tests first, then a tethered hover, then real flights in a safe open area, following local drone rules. I read the logs, change what needs changing and rebuild.
